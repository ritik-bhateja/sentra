🔐 NEW API ENDPOINTS:

Authentication:
  GET  /auth/google              - Initiate OAuth
  GET  /auth/google/callback     - OAuth callback
  POST /auth/logout              - Logout user
  GET  /auth/me                  - Get current user
  GET  /auth/verify              - Verify token

Protected Endpoints (require JWT cookie):
  POST /query                    - Send chat query
  POST /api/sessions             - Create session
  GET  /api/sessions/{user_id}   - Get user sessions
  GET  /api/sessions/{id}/turns  - Get session messages
  PUT  /api/sessions/{id}        - Update session
  DELETE /api/sessions/{id}      - Delete session

🔍 TROUBLESHOOTING:

Issue: "redirect_uri_mismatch"
→ Verify Google Console redirect URI: http://localhost:5000/auth/google/callback

Issue: "Not authenticated" 
→ Check browser cookies (DevTools → Application → Cookies)
→ Look for: sentra_jwt_token

Issue: Database connection failed
→ Check RDS security group allows your IP
→ Run: python setup_auth_database.py

Issue: CORS error
→ Backend must be on port 5000
→ Frontend must be on port 5173
